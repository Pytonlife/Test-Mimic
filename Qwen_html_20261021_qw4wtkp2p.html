🌐 Signaling-серверы авто-выбор
Подключение идёт параллельно ко всем серверам — побеждает первый ответивший. Данные и голос после этого идут напрямую P2P (сервер нужен только для «знакомства»).
Свой сервер (peerjs-server):
npx peerjs-server --port 9000 --key mykey
# → http://localhost:9000?key=mykey
🚀 Как задеплоить (важно про Google Sites) прочитай

⚠️ Google Sites НЕ подходит — микрофон там работать не будет.

Google Sites встраивает сторонний HTML в sandboxed iframe без атрибута allow="microphone". По спецификации Permissions Policy для cross-origin iframe доступ к микрофону по умолчанию запрещён, а getUserMedia() в sandboxed-iframe требует allow-same-origin. Результат: NotAllowedError — игра не сможет ни слушать, ни записывать. Это ограничение Google, его нельзя обойти из кода страницы.

✅ Рабочие бесплатные варианты:

  • GitHub Pages — самый простой. Создай репозиторий, закинь index.html, включи Pages в Settings. HTTPS из коробки.
  • Netlify Drop — перетащи файл на app.netlify.com/drop, получишь ссылку за 10 секунд.
  • Cloudflare Pages / Vercel — тоже бесплатно и с HTTPS.
  • Локально: python -m http.server 8000 → http://localhost:8000

Если очень хочется именно Google Sites:

Задеплой игру на GitHub Pages, а в Google Sites вставь её через «Встроить → По URL». Но и тогда микрофон останется заблокированным из-за iframe — подойдёт только как витрина/лендинг со ссылкой-кнопкой на настоящую игру.

💡 Про «сервер на компе владельца»:

Так и работает! Signaling-сервер (PeerJS Cloud или свой peerjs-server) нужен только чтобы игроки нашли друг друга — это килобайты трафика. Весь голос и все данные после этого идут напрямую между браузерами (WebRTC P2P). Хостом раунда является браузер создателя комнаты — свой гейм-сервер покупать не нужно.
